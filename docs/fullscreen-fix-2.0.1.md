# 2.0.1 全屏分页修复

## 问题与原因

正式安装包隐藏阅读工具栏后，正文保留旧分页高度，导致屏幕下部出现大块空白。普通调试测试未暴露这个问题。

旧分页缓存将 `Size.toString()` 放入布局签名。Flutter 的 Profile/Release 编译启用 `--delete-tostring-package-uri=dart:ui` 等选项，尺寸的调试字符串不能作为业务缓存依据，导致高度不同的布局被认为相同。

## 修复

分页签名改为比较实际宽、高、间距模式、字体与缩放数值的 Dart Record；PageView 的 Key 同样使用结构化值。保留原来的正文锚点恢复逻辑、背景、字体和间距设置。

版本更新为 2.0.1 / versionCode 3，沿用此前包名与测试签名，支持覆盖安装。

## 验证

- 新回归测试模拟 Release 中相同的尺寸描述：修复前失败，修复后通过。
- 中间页切换测试验证正文区域加高、页数减少、原锚点仍可见，以及恢复工具栏后重新按原尺寸分页。
- 完整 **33 项测试通过**，静态检查 **No issues found**。
- 使用 Android 16 / Pixel 5 模拟器和真实书源同一章验证正式安装包：修复前切换前后均为 19 页；修复后普通模式 19 页、全屏模式 15 页，当前页可见字符从 184 增至 238，旧阅读锚点仍在新页内。具体页数随设备、字体与间距设置变化。
- 测试章节只保存在工作区，没有将小说正文加入代码库。

尚未在用户的华为实体手机上验证。
